# Hi there, I'm Daniel Cahen 👋

I am a **PhD Botanist at the Royal Botanic Gardens, Kew**, specializing in the family **Rhamnaceae**. 

## 🛠 The Biologist's Toolkit
I am currently developing a suite of experimental AI-powered prototypes. 

- 🌿 **Flora Scout**: A search-grounded multi-access key.  
  [📂 Code](https://github.com/gouania/flora-scout) | [🚀 Live App](https://flora-scout-plant-id-guide-1032064257204.us-west1.run.app/)

- 🧬 **Taxon Profiles**: Diagnostic descriptions and side-by-side comparisons.  
  [📂 Code](https://github.com/gouania/taxon-profiles) | [🚀 Live App](https://taxon-profiles-937134952254.us-west1.run.app)

- 📋 **BioKey AI**: Generating identification keys from raw text.  
  [📂 Code](https://github.com/gouania/biokey-ai) | [🚀 Live App](https://biokey-ai-327899095874.us-west1.run.app/)

- 🌲 **Cedrus-BioKey Pilot**: "Strict Mode" identification using fixed datasets.  
  [📂 Code](https://github.com/gouania/cedrus-biokey-pilot) | [🚀 Live App](https://cedrus-biokey-data-1089409921036.us-west1.run.app/)

- 📑 **Scientific Name Extractor**: Taxonomic name extraction utility.  
  [📂 Code](https://github.com/gouania/scientific-name-extractor) | [🚀 Live App](https://scientific-name-extractor-978100405288.us-west1.run.app/)

- 📜 **Botanical Authorities**: Biographical search for taxonomists.  
  [📂 Code](https://github.com/gouania/botanical-authorities) | [🚀 Live App](https://botanical-authorities-612559298112.us-west1.run.app)
